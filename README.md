# Team 3 – Horror Movies Preprocessing

A five-member team project focused on exploratory data analysis and machine-learning data preprocessing using a Horror Movies dataset.

## Dataset Source

[Kaggle – Horror Movies Dataset](https://www.kaggle.com/datasets/sujaykapadnis/horror-movies-dataset)

## Project Workflow

1. Dataset understanding and EDA
2. Missing-value analysis and handling
3. Duplicate and outlier analysis
4. Encoding and scaling
5. Feature selection and validation

## Collaboration

The team will maintain one evolving Jupyter Notebook. Each member will continue from the previous member's latest branch and submit a Pull Request for review.

## Running the Project

Download the dataset from the Kaggle source, place `horror_movies.csv` in the `dataset/` folder, install the required Python libraries, and execute the notebook from beginning to end in Google Colab or Jupyter Notebook.
